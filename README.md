# Telemetry

Live CPU, GPU, memory and storage monitoring with temperature gauges and activity
graphs.

- **KDE Plasma 6:** the existing widget is in `org.dfuse.hardwaremonitor/`.
- **Windows 11:** see [Windows setup](windows/README.md). Telemetry includes its
  own sensor collector, dashboard and Windhawk taskbar integration.

The Windows implementation is on the `windows-taskbar` development branch.
